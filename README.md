# CV. Abadi Timur Fiber – Production Website

## Overview
This repository contains a **stand‑alone, deploy‑ready** static website for **CV. Abadi Timur Fiber**. The page showcases:
- Company profile and service catalog
- Neumorphic 3D UI style (soft UI) with Tailwind‑CSS utility classes
- Fully responsive layout (mobile‑first)
- Interactive contact & booking form
- Floating WhatsApp button for instant chat

All design tokens, color palette, shadows and typography follow the **figma‑tokens.json** file included in the repo. The UI mirrors the original SVG mock‑up (`Untitled.svg`).

## How to Deploy
1. **Static hosting** – copy the whole `pt-timur-abadi-fiber-production` folder to your web server (e.g., Vercel, Netlify, GitHub Pages, traditional Apache/Nginx).
2. No build step is required because the page uses **Tailwind CDN** (`<script src="https://cdn.tailwindcss.com"></script>`). The custom neumorphic utilities are defined in `assets/css/style.css`.
3. Ensure the server serves the `index.html` as the entry point.

### Example (GitHub Pages)
```bash
# Assuming you have a Git repo already
git add .
git commit -m "Add production site"
git push origin main
# Enable GitHub Pages in repo Settings → source: main / (root)
```
The site will be available at `https://<username>.github.io/<repo>/`.

## Customisation
- **Colors / Shadows** – edit `figma-tokens.json` and the corresponding CSS variables in `style.css`.
- **Content** – modify the HTML inside `index.html`; keep the class names (`neu-flat`, `neu-btn`, etc.) to retain the neumorphic look.
- **Tailwind Config** – if you need extra utilities, switch to a local Tailwind build (install via npm) and add your custom config.

## Development
Open `index.html` directly in a browser for instant preview. For live‑editing, use any editor (VS Code, Sublime, etc.) – the page reloads automatically when saved.
